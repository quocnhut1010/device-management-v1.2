# SQL

SQL scripts are organized by purpose.

```text
sql/
├── schema/
├── seed/
└── scripts/
```

## schema

Contains table structure, primary keys, foreign keys, indexes, and constraints.

## seed

Contains development data for local testing.

## scripts

Contains helper scripts such as reset or drop database scripts.
